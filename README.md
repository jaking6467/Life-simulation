# 🏙️ เส้นทางชีวิต (Life Simulation)

เกมจำลองชีวิตแนว **Walk of Life** เล่นได้ 2–4 คน แบบ **ผลัดกันเล่นคนละ 1 สัปดาห์** —
ผู้เล่นคนที่ 2, 3, 4 ต้องรอให้คนก่อนหน้า "จบสัปดาห์" ก่อนจึงจะได้เล่น

แต่ละสัปดาห์มีเวลา 60 ชั่วโมง เดินไปตามอาคารในเมือง ทำงาน เรียน กิน นอน อาบน้ำ ออกกำลังกาย แต่งบ้าน ลงทุน
แล้วรับคะแนนตามสภาพชีวิตทุกสุดสัปดาห์ ครบจำนวนสัปดาห์ ใครคะแนนรวมสูงสุดชนะ

## ฟีเจอร์

**ระบบเทิร์น**
- ลำดับการเล่นสุ่มตอนเริ่มเกม มีผู้เล่นปัจจุบันได้ทีละคน เซิร์ฟเวอร์ปฏิเสธคำสั่งของคนที่ยังไม่ถึงตา
- คนที่รอเห็นว่าตาของใคร อยู่ที่ไหน ทำอะไรล่าสุด และ "อีกกี่ตาจะถึงคุณ" มีเสียงแจ้งเตือนเมื่อถึงตาของเรา
- ตั้งเวลาเล่นจริงต่อสัปดาห์ได้ (1–5 นาที หรือไม่จำกัด) หมดเวลาระบบจบสัปดาห์ให้ หมดเวลา 2 ครั้งติดบอทเล่นแทนจนกว่าจะกดกลับมา
- หลุดการเชื่อมต่อ: รอ 20 วินาทีแล้วบอทเล่นแทน รีเฟรชหน้าแล้วกลับเข้าห้องเดิมได้ ออกจากห้องกลางเกมมีบอทเล่นแทนจนจบ

**ระบบในเกม**
- **แผนที่เมือง 18 อาคาร** รอบถนนวงแหวน เดินไกลเสียเวลามาก ซื้อจักรยาน มอเตอร์ไซค์ หรือรถยนต์เพื่อเดินทางเร็วขึ้น
- **ค่าสถานะ** สุขภาพ ความสุข ความสะอาด เงิน การศึกษา อาชีพ — ต้องกินอย่างน้อยสัปดาห์ละมื้อ อาบน้ำ ซื้อเสื้อผ้าใหม่ จ่ายค่าเช่า ความสุขต่ำเกินไปจะหมดไฟทำงานไม่ได้
- **งาน 27 ตำแหน่ง** ใน 12 สถานที่ ต้องมีวุฒิ ประสบการณ์ และชุดที่เหมาะ แต่ละที่ทำงานมีสวัสดิการ (ไก่ทอดฟรี ห้องอาบน้ำพนักงาน ฯลฯ)
- **มหาวิทยาลัย 9 หลักสูตร** ตั้งแต่ กศน. ถึง MBA และแพทยศาสตร์ เรียนออนไลน์ที่บ้านได้ถ้ามีคอมพิวเตอร์
- **บ้านและของแต่งบ้าน**: แฟลตราคาถูก หรือคอนโดหรู ของแต่งบ้าน 11 ชิ้นที่มีผลทุกสัปดาห์ (หุ่นยนต์ดูดฝุ่นติดอาวุธกันขโมยได้!)
- **การเงิน**: ฝากเงิน (กันขโมย มีดอกเบี้ย) กู้เงิน หุ้น 3 ตัว และทองคำ ลอตเตอรี่ออกทุก 2 สัปดาห์ สัตว์เลี้ยง (แมวนำโชค สุนัขทำให้ขยัน)
- **บทบาท 8 แบบ** แต่ละบทบาทมีความสามารถพิเศษและภารกิจของตัวเอง: คนบ้างาน ศิลปิน นักเก็บของเก่า หมอดู หนอนหนังสือ สายฟิต วัยเกษียณ อินฟลูเอนเซอร์
- **เหตุการณ์**: ข่าวทั้งเมืองทุกสัปดาห์ (สงกรานต์ ฝุ่น PM2.5 สัตว์ประหลาดยักษ์ตีกันจนอาคารปิด ฯลฯ) เรื่องให้ตัดสินใจตอนเริ่มตา และเรื่องไม่คาดฝันทุกสุดสัปดาห์
- **คะแนนทุกสัปดาห์** 7 หมวด: สุขภาพ ความสุข ความสะอาด การศึกษา อาชีพ ความมั่งคั่ง บ้าน + โบนัสจากภารกิจ

**การเล่น**
- ออนไลน์: สร้างห้อง / เข้าห้องด้วยรหัส 5 ตัว หรือลิงก์ / จับคู่ด่วน, เลือกบทบาทในห้องรอ, แชทและอีโมจิ
- ออฟไลน์: เล่นกับบอท หรือผลัดกันเล่นหลายคนบนเครื่องเดียว (ไม่ต้องมีเซิร์ฟเวอร์)
- บอทวางแผนชีวิตเอง (กิน อาบน้ำ หางาน เรียน ทำงาน ใช้ความสามารถของบทบาท)
- ใช้ได้ทั้งคอมพิวเตอร์และมือถือ

## โครงสร้างโปรเจกต์

```
backend/
  server.js               เซิร์ฟเวอร์ Express + Socket.io (เสิร์ฟหน้าเว็บที่ build แล้วด้วย)
  src/game/               ตัวเกม — ใช้ร่วมกันทั้งเซิร์ฟเวอร์และโหมดออฟไลน์ในเบราว์เซอร์
    engine.js             กติกา สถานะเกม กิจกรรมในแต่ละอาคาร และการเดินเทิร์น
    city.js               แผนที่เมือง ระยะทาง และพาหนะ
    jobs.js courses.js items.js roles.js events.js rules.js   ข้อมูลเกมและค่าสมดุล
    bot.js                สมองบอท (ใช้ตอนหมดเวลา/หลุดด้วย)
    room.js               ห้องเกม ห้องรอ แชท ตัวจับเวลา
    roomManager.js        จัดการหลายห้อง + แปลงข้อความจากผู้เล่น
  test/                   เทสต์ (node:test)
  scripts/simulate.js     จำลองเกมบอทหลายร้อยเกมเพื่อดูสมดุล
frontend/                 React + Vite
  src/screens/            หน้าแรก ห้องรอ หน้าเกม
  src/components/         แผนที่เมือง แผงเทิร์นและกิจกรรม ผู้เล่น สรุปสุดสัปดาห์ ฯลฯ
  src/net/                การเชื่อมต่อออนไลน์ (socket.io) และออฟไลน์ (รันห้องในเบราว์เซอร์)
```

## รันบนเครื่อง

ต้องใช้ Node.js 18 ขึ้นไป

```bash
npm run install:all        # ติดตั้งทั้ง backend และ frontend

# เทอร์มินัลที่ 1: เซิร์ฟเวอร์เกม (พอร์ต 3001)
cd backend && npm run dev

# เทอร์มินัลที่ 2: หน้าเว็บ (http://localhost:5173 ต่อเซิร์ฟเวอร์ให้อัตโนมัติ)
cd frontend && npm run dev
```

หรือ build แล้วรันที่เดียว: `npm run build && npm start` แล้วเปิด http://localhost:3001

## ทดสอบ

```bash
npm test                   # เทสต์กติกาและระบบเทิร์น
npm run simulate           # จำลองเกมบอท 200 เกม แสดงคะแนนเฉลี่ยและอัตราชนะของแต่ละบทบาท
```

ปรับสมดุลเกม (ค่าแรง ค่าเทอม ราคาของ ภารกิจ ฯลฯ) ได้ที่ `backend/src/game/rules.js`, `jobs.js`, `courses.js`, `items.js`, `roles.js`, `events.js` แล้วรัน `npm run simulate` ดูผล

## บันทึกเกม 💾

- **ออฟไลน์**: บันทึกอัตโนมัติทุกครั้งที่มีคนเล่น (เก็บในเบราว์เซอร์) กดออกหรือปิดหน้าแล้วกลับมาเล่นต่อได้จากหน้าแรก → "💾 เล่นต่อ"
  กด 💾 ในเกมเพื่อบันทึกลงช่อง (3 ช่อง) หรือดาวน์โหลดไฟล์เซฟ `.json` ไปเปิดต่อเครื่องอื่น (หน้าแรก → 📂 เปิดไฟล์เซฟ)
  เซฟอัตโนมัติจะถูกแทนที่เมื่อเกมใหม่ "เริ่มเล่นจริง" เท่านั้น (มีถามก่อน) และลบเมื่อออกจากเกมที่จบแล้ว
- **ออนไลน์**: เซิร์ฟเวอร์บันทึกทุกห้องลงไฟล์ (สูงสุดทุก 10 วินาทีเมื่อมีการเปลี่ยนแปลง และตอนปิดด้วย SIGINT/SIGTERM)
  รีสตาร์ตแล้วผู้เล่นเชื่อมต่อกลับด้วยเครื่องเดิมก็เล่นต่อได้ทันที ดาวน์โหลดไฟล์เซฟของเกมออนไลน์ไปเล่นต่อแบบออฟไลน์บนเครื่องเดียวได้
  - ตั้งตำแหน่งไฟล์ด้วย `SAVE_FILE` (ค่าเริ่มต้น `backend/data/rooms.json`, ตั้ง `SAVE_FILE=off` เพื่อปิด)
  - บนโฮสต์ที่ดิสก์หายทุกครั้งที่ deploy (เช่น Render แบบไม่มี persistent disk) ห้องจะอยู่รอดแค่การรีสตาร์ต ไม่รอดการ deploy ใหม่
- เปลี่ยนโครงสร้าง state ของเกมจนเซฟเก่าใช้ไม่ได้ → เพิ่ม `STATE_VERSION` ใน `backend/src/game/engine.js` (เซฟเก่าจะถูกปฏิเสธอย่างสุภาพแทนที่จะพัง)

## Deploy

**แบบเดียวจบ (แนะนำ)** — เซิร์ฟเวอร์เสิร์ฟหน้าเว็บเอง ไม่ต้องตั้งค่า URL
- Build command: `npm run install:all && npm run build`
- Start command: `npm start`
- Health check: `/api/status`

**แยก backend / frontend**
- Backend (เช่น Render, root directory `backend`): build `npm install`, start `node server.js`
- Frontend บน Vercel: มี `vercel.json` กำหนดคำสั่ง install/build ไว้แล้ว ใช้ได้ทั้ง root directory เป็น `frontend` หรือรากของ repo
  ตั้ง environment variable `VITE_SOCKET_URL` (หรือ `REACT_APP_SOCKET_URL` แบบเดิม) เป็น URL ของ backend เพื่อเล่นออนไลน์
  (ถ้าไม่ตั้ง จะเล่นได้เฉพาะโหมดออฟไลน์)
- หน้าเว็บใช้โค้ดเกมจาก `backend/src/game` ด้วย ถ้า root directory เป็น `frontend` ต้องเปิดตัวเลือก
  "Include files outside the root directory in the Build Step" (เปิดอยู่แล้วโดยค่าเริ่มต้น)
- ถ้าต้องการจำกัดโดเมนที่เชื่อมต่อได้ ตั้ง `CORS_ORIGIN` ที่ backend (คั่นด้วย `,`)

**GitHub Pages** — `cd frontend && npm run build:docs` แล้ว commit โฟลเดอร์ `docs/`
เล่นออฟไลน์ได้ทันที ส่วนออนไลน์ต้อง build พร้อม `VITE_SOCKET_URL`
