# 🎡 เส้นทางชีวิต (Life Simulation)

เกมกระดานจำลองชีวิตสไตล์ **The Game of Life** เล่นได้ 2–4 คน แบบ **ผลัดกันเล่นทีละคน** —
ผู้เล่นคนที่ 2, 3, 4 ต้องรอให้คนก่อนหน้าเล่นจบตาก่อนจึงจะได้เล่น

เรียนต่อหรือทำงาน → เลือกอาชีพ → แต่งงาน มีลูก → ซื้อบ้าน → ลงทุน → เกษียณ
ใครมี **เงินสด − หนี้ + มูลค่าบัตรความสุข** มากที่สุดเป็นผู้ชนะ

## ฟีเจอร์

**ระบบเทิร์น**
- ลำดับการเล่นสุ่มตอนเริ่มเกม มีผู้เล่นปัจจุบันได้ทีละคน เซิร์ฟเวอร์ปฏิเสธคำสั่งของคนที่ยังไม่ถึงตา
- หน้าจอบอกชัดว่าตาของใคร กำลังทำอะไร และ "อีกกี่ตาจะถึงคุณ" มีเสียงแจ้งเตือนเมื่อถึงตาของเรา
- ตั้งเวลาตัดสินใจได้ (30 วินาที–2 นาที หรือไม่จำกัด) หมดเวลาระบบเลือกให้ หมดเวลา 2 ครั้งติดระบบเล่นแทนจนกว่าจะกดกลับมา
- หลุดการเชื่อมต่อ: รอ 20 วินาทีแล้วระบบเล่นแทน รีเฟรชหน้าแล้วกลับเข้าห้องเดิมได้ ออกจากห้องกลางเกมมีบอทเล่นแทนจนจบ
- ช่องหยุด (บังคับหยุด), ทางแยก (เลือกเส้นทางกลางการเดิน), การ์ด "ข้ามตา" และ "หมุนอีกครั้ง"

**ระบบในเกม**
- **อาชีพ 12 อาชีพ** (ไม่ซ้ำกันในเกม) มี 4 ขั้นตำแหน่ง และ **สิทธิ์พิเศษ**: เมื่อคนอื่นจ่ายเงินหมวดของอาชีพคุณ เงินเข้ากระเป๋าคุณ (หมอได้ค่ารักษา ช่างได้ค่าซ่อมรถ นักบัญชีได้ภาษี ฯลฯ)
- **การศึกษา**: เรียนมหาวิทยาลัย (มีหนี้แต่ได้อาชีพเงินเดือนสูง) หรือทำงานเลย, เรียนปริญญาโทภาคค่ำ/เปลี่ยนงานช่วงวัยกลางคน
- **ครอบครัว**: แต่งงาน (ทุกคนหมุนใส่ซอง) หรือครองโสด, มีลูก (มีค่าเลี้ยงดูทุกวันเงินเดือนออก), สัตว์เลี้ยง
- **บ้าน 10 หลัง**: ซื้อ/ขาย ราคาขายขึ้นกับการหมุน
- **การเงิน**: เงินกู้ (กู้ 20,000 คืน 25,000 และกู้อัตโนมัติเมื่อเงินไม่พอ), ประกันรถ/บ้าน/สุขภาพ, **ใบหุ้นหมายเลข 1–10** ที่จ่ายปันผลเมื่อใครก็ตามหมุนได้เลขนั้น
- **การ์ดชีวิต 50+ ใบ**: บางใบให้ตัดสินใจ (ลงทุนคริปโต/สตาร์ทอัพ) บางใบโต้ตอบกับคนอื่น (ฟ้องร้อง แข่งขัน วันเกิด)
- **บัตรความสุข** มูลค่าซ่อนไว้ เปิดเผยตอนจบเกม
- **เกษียณ**: คฤหาสน์เศรษฐี (เสี่ยง) หรือบ้านสวนชนบท (ปลอดภัย) เกษียณก่อนได้โบนัส

**การเล่น**
- ออนไลน์: สร้างห้อง / เข้าห้องด้วยรหัส 5 ตัว หรือลิงก์ / จับคู่ด่วน, แชทและอีโมจิ
- ออฟไลน์: เล่นกับบอท หรือผลัดกันเล่นหลายคนบนเครื่องเดียว (ไม่ต้องมีเซิร์ฟเวอร์)
- บอทมีนิสัยต่างกัน (ใจกล้า/รักครอบครัว/รอบคอบ)
- ใช้ได้ทั้งคอมพิวเตอร์และมือถือ

## โครงสร้างโปรเจกต์

```
backend/
  server.js               เซิร์ฟเวอร์ Express + Socket.io (เสิร์ฟหน้าเว็บที่ build แล้วด้วย)
  src/game/               ตัวเกม — ใช้ร่วมกันทั้งเซิร์ฟเวอร์และโหมดออฟไลน์ในเบราว์เซอร์
    engine.js             กติกา สถานะเกม และการเดินเทิร์น
    board.js              กระดานและทางแยก
    careers.js houses.js cards.js rules.js   ข้อมูลเกมและค่าสมดุล
    bot.js                สมองบอท (ใช้ตอนหมดเวลา/หลุดด้วย)
    room.js               ห้องเกม ห้องรอ แชท ตัวจับเวลา
    roomManager.js        จัดการหลายห้อง + แปลงข้อความจากผู้เล่น
  test/                   เทสต์ (node:test)
  scripts/simulate.js     จำลองเกมบอทหลายร้อยเกมเพื่อดูสมดุล
frontend/                 React + Vite
  src/screens/            หน้าแรก ห้องรอ หน้าเกม
  src/components/         กระดาน วงล้อ การตัดสินใจ การเงิน ผู้เล่น ฯลฯ
  src/net/                การเชื่อมต่อออนไลน์ (socket.io) และออฟไลน์ (รันห้องในเบราว์เซอร์)
```

## รันบนเครื่อง

ต้องใช้ Node.js 18 ขึ้นไป

```bash
npm run install:all        # ติดตั้งทั้ง backend และ frontend

# เทอร์มินัลที่ 1: เซิร์ฟเวอร์เกม (พอร์ต 3001)
cd backend && npm run dev

# เทอร์มินัลที่ 2: หน้าเว็บ (http://localhost:5173 ต่อเซิร์ฟเวอร์ให้อัตโนมัติ)
cd frontend && npm run dev
```

หรือ build แล้วรันที่เดียว: `npm run build && npm start` แล้วเปิด http://localhost:3001

## ทดสอบ

```bash
npm test                   # เทสต์กติกาและระบบเทิร์น
npm run simulate           # จำลอง 300 เกม แสดงคะแนนเฉลี่ยตามเส้นทาง/อาชีพ
```

ปรับสมดุลเกม (เงินเดือน ราคาบ้าน ค่าประกัน ฯลฯ) ได้ที่ `backend/src/game/rules.js`, `careers.js`, `houses.js`, `cards.js` แล้วรัน `npm run simulate` ดูผล

## Deploy

**แบบเดียวจบ (แนะนำ)** — เซิร์ฟเวอร์เสิร์ฟหน้าเว็บเอง ไม่ต้องตั้งค่า URL
- Build command: `npm run install:all && npm run build`
- Start command: `npm start`
- Health check: `/api/status`

**แยก backend / frontend**
- Backend (เช่น Render, root directory `backend`): build `npm install`, start `node server.js`
- Frontend (เช่น Vercel, root directory `frontend`): framework **Vite**, output directory `build`
  และตั้ง environment variable `VITE_SOCKET_URL` (หรือ `REACT_APP_SOCKET_URL` แบบเดิม) เป็น URL ของ backend
- หน้าเว็บใช้โค้ดเกมจาก `backend/src/game` ด้วย ต้องเปิดตัวเลือกให้ build เห็นไฟล์นอก root directory
  (Vercel: "Include files outside the root directory in the Build Step")
- ถ้าต้องการจำกัดโดเมนที่เชื่อมต่อได้ ตั้ง `CORS_ORIGIN` ที่ backend (คั่นด้วย `,`)

**GitHub Pages** — `cd frontend && npm run build:docs` แล้ว commit โฟลเดอร์ `docs/`
เล่นออฟไลน์ได้ทันที ส่วนออนไลน์ต้อง build พร้อม `VITE_SOCKET_URL`
